# Лабораторна робота: автоматичне укладання частотних словників

Програма будує реляційну базу SQLite для трьох художніх творів української літератури та обчислює частотні й статистичні показники агрегуючими SQL-запитами.

## Запуск

У VS Code: відкрити папку `Lab1Bd`, вибрати інтерпретатор `.venv`, запустити конфігурацію **Запустити лабораторну** (F5).

У терміналі:

```bash
.venv/bin/python main.py
```

```bash
.venv/bin/python -m unittest discover -s tests
```

На іншому комп'ютері спочатку створити середовище:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

- Лінгвістична однорідність: художній стиль, жанр повісті, українська проза кінця XIX — початку XX ст.
- Статистична однорідність: механічна вибірка (суцільний фрагмент від початку твору), по 20 000 слововживань, 20 підвибірок по 1000 слововживань.
- Обсяг оцінено відносною похибкою `δ = t · √((1 − p) / (p · N))`, `t = 1,96`.

## База даних

Структура розвиває рекомендовану [ER-модель](https://drawsql.app/teams/infosoft-1/diagrams/text-structure-parsing).

| Таблиця | Вміст |
| --- | --- |
| `texts`, `sentences`, `words`, `pos` | структура тексту; кожне слововживання є окремим рядком, тому повтори збережені |
| `tokens` | представлення для зручних запитів |
| `freq_forms` | частотний словник словоформ (варіант 1 методички): словоформа, `abs_freq`, `part_1`…`part_20` |
| `freq_wordforms` | частотний словник із лематизацією (варіант 2): частина мови, лема, словоформа, `abs_freq`, `part_1`…`part_20` |
| `freq_lemmas` | частотний словник лем |
| `freq_pos` | частотний словник частин мови |
| `tfidf` | TF-IDF за формулою в SQL і значення scikit-learn |
| `pos_statistics` | середнє, сигма, варіація, відносні похибки |
| `subsample_clusters` | кластеризація підвибірок KMeans |

## Обчислені показники

Частини мови, TF-IDF, довжина слів і речень, лексичне багатство, індекс повторюваності, гапакси, частотний спектр, найчастотніші леми й словоформи, спільна лексика (коефіцієнт Жаккара), статистичні характеристики за підвибірками, кластеризація.

Усі запити зібрані у файлі `queries.py`.
